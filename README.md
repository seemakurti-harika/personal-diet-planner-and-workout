# 🤖 AI Health Companion

An intelligent web application that provides **personalized meal plans, food analysis, and health insights** using AI.

---

## 🚀 Features

- 🥗 **Personalized Meal Planning**
  - Generates a 7-day meal plan based on user health profile
  - Includes calories, macros, and preparation tips

- 📸 **Food Image Analysis**
  - Upload food images
  - Get estimated calories and nutrition breakdown

- 🧠 **AI Health Insights**
  - Ask health-related questions
  - Get science-backed recommendations

- 👤 **Custom Health Profile**
  - Goals, diet preferences, restrictions, routines
  - Fully customizable

- 📥 **Download Option**
  - Export meal plans as text files

---

## 🛠️ Tech Stack

- **Frontend/UI:** Streamlit  
- **Backend Logic:** Python  
- **AI Model:** Google Gemini API  
- **Image Processing:** Pillow

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository


git clone https://github.com/your-username/ai-health-companion.git

cd ai-health-companion


---

### 2️⃣ Install Dependencies


pip install -r requirements.txt


---

### 3️⃣ Add API Key

Create a `.env` file and add:


GOOGLE_API_KEY=your_api_key_here

---

### 4️⃣ Run the App
streamlit run Nutrition.py
